# Design Image Prompting

Use this reference when the user wants beautiful concept images, boards, or interface visuals rather than only a technical diagram.

## Prompt Formula

Use this shape:

`subject + composition + visual language + materials + palette + lighting + interface constraints + exclusions`

## Example Prompt Skeleton

```text
Design a [subject] presented as a [composition]. Use a [visual language] with [materials or surfaces]. 
Palette: [dominant colors + accent]. Lighting: [lighting cue]. 
Show [key UI or content constraints]. Avoid [exclusions].
```

## Strong Constraints

- one focal area
- legible hierarchy
- restrained palette
- intentional negative space
- minimal chrome
- labels that look designed, not autogenerated

## Useful Exclusions

- no lorem ipsum blocks
- no extra floating widgets
- no warped text
- no redundant panels
- no gratuitous glow
- no cluttered backgrounds

## Variant Strategy

Return three prompt variants when the user wants exploration:

1. precise enterprise board
2. bold editorial concept
3. premium product-marketing hybrid

Keep the underlying workflow constant while changing the aesthetic treatment.

## Inputs
- `subject` (string, required)
- `composition` (string), `visual_language` (string), `materials` (string), `palette` (string), `lighting` (string)
- `interface_constraints` (string) - key UI or content constraints to show
- `exploration` (boolean, default: false) - true -> return three variants

## Outputs
- One prompt per the formula + skeleton
- Exploration mode: three variants with the workflow constant and only the aesthetic treatment changed

## Example
Input: concept board for a fintech dashboard.
1. Formula: subject "fintech dashboard concept" + composition "editorial board" + visual language "minimal fintech" + palette "navy/emerald restrained" + lighting "soft studio" + constraints "show 3 KPIs, one chart" + exclusions.
2. Constraints enforced: one focal area, legible hierarchy, minimal chrome.
3. Exploration: precise enterprise board / bold editorial / premium product-marketing hybrid.

## Errors & edge cases
- Lorem ipsum or warped text in output: excluded by rule - regenerate, don't patch.
- User wants exploration: always three variants, never one; keep the workflow constant across them.
- Cluttered backgrounds or redundant panels: listed exclusions - cut them, don't decorate around them.
