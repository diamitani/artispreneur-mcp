# Elite Design Studio

Agency-level branding, visual identity systems, and design direction.

## Core Capabilities
- **Brand Strategy**: Positioning, archetypes, messaging architecture
- **Visual Identity**: Logo systems, color palettes, typography, iconography
- **Design Systems**: Component libraries, pattern guides, usage documentation
- **Brand Guidelines**: Comprehensive brand books with rules and examples
- **Creative Direction**: Campaign concepts, art direction, mood boards

## Identity Deliverables
- **Logo Suite**: Primary, secondary, icon, wordmark, monochrome variants
- **Color System**: Primary, secondary, accent palettes with hex/RGB/CMYK/PMS values
- **Typography**: Heading and body font pairings with scale and usage rules
- **Imagery Style**: Photography direction, illustration style, icon system
- **Applications**: Business cards, letterhead, social templates, signage

## Workflow
1. Discovery: Brand audit, competitive analysis, stakeholder interviews
2. Strategy: Define positioning, personality, and visual direction
3. Concept: Explore 2-3 design directions with rationale
4. Refinement: Develop selected direction into full identity system
5. Documentation: Create comprehensive brand guidelines

## Pitfalls
- Don't design for trends — build identities with longevity
- Test at all sizes: billboard to favicon
- Ensure accessibility: color contrast, legible typography
- Include practical application examples, not just theory

## Inputs
- `brand` (string, required) - company/product, audience, market
- `scope` (enum: full-identity / refresh / guidelines-only, required)

## Outputs
- Brand strategy: positioning, archetypes, messaging architecture
- Identity deliverables: logo suite, color system, typography scale, imagery style, applications (cards, social, signage)
- Comprehensive brand guidelines document

## Example
Input: full identity for a coffee roastery.
1. Discovery: brand audit, competitor analysis, stakeholder interviews.
2. Strategy: positioning (third-wave, approachable), archetype, visual direction.
3. Concept: 2-3 directions with rationale; refine the winner.
4. Deliverables: logo suite, palette with hex/RGB/CMYK/PMS, type pairings, packaging mockups; guidelines doc. Tested billboard-to-favicon; accessibility contrast checked.
