# HUMINT — Human Intelligence Skills

## Overview

HUMINT teaches and simulates human intelligence skills — not espionage, but the art of understanding people. Drawing from fields like active listening, behavioral observation, emotional intelligence, and negotiation, this skill helps users build deeper self-awareness and stronger interpersonal abilities.

## When to Use

- A user wants to improve their emotional intelligence or people-reading skills
- Someone is preparing for a difficult conversation or negotiation
- The user wants to practice active listening or empathy-building exercises
- Someone is curious about behavioral observation and non-verbal communication
- A user wants to understand themselves better through structured self-reflection

## How It Works

1. Identify which interpersonal skill the user wants to develop
2. Provide a brief conceptual framework for the skill
3. Offer practical exercises, scenarios, or role-play simulations
4. Debrief with reflective questions to solidify learning
5. Suggest real-world practice opportunities

## Steps

1. **Assess Focus Area**: Determine which skill they want to work on (listening, observation, negotiation, empathy, self-awareness)
2. **Teach the Framework**: Explain the key concepts in accessible language
3. **Simulate or Role-Play**: Create realistic scenarios for the user to practice
4. **Debrief**: Ask what they noticed, what was challenging, what they learned
5. **Assign Practice**: Suggest a low-stakes real-world exercise to try before next session

## Common Pitfalls

- Don't frame this as manipulation — the goal is understanding, not control
- Avoid clinical or diagnostic language (this is skill-building, not therapy)
- Don't over-complicate — keep frameworks simple and actionable
- Respect the user's boundaries — don't push into deeply personal territory uninvited
- Don't claim these skills work universally — individual and cultural differences matter

## Inputs
- The user's focus area: emotional intelligence, people-reading, difficult-conversation prep, active listening/empathy exercises, behavioral observation and non-verbal communication, or structured self-reflection.
- A scenario to simulate if one is given (e.g. an upcoming negotiation or difficult conversation).

## Outputs
- A brief conceptual framework for the chosen skill, in accessible language.
- Practical exercises, scenarios, or role-play simulations.
- A debrief with reflective questions (what they noticed, what was challenging, what they learned) to solidify learning.
- A low-stakes real-world practice opportunity to try before the next session.

## Example
Prepare for a difficult conversation:

1. Assess the focus area — e.g. empathetic listening under pressure.
2. Teach the framework — key concepts in plain language.
3. Simulate: run a realistic role-play of the conversation.
4. Debrief — ask what they noticed, what was challenging, what they learned.
5. Assign practice: one low-stakes real-world listening exercise to try before next session.
