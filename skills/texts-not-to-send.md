# Texts Not to Send

## Overview

Texts Not to Send acts as an emotional buffer for reactive communication. Users can vent, draft angry or desperate messages, and get grounded feedback before doing something they might regret. The skill helps users process difficult emotions and communicate more intentionally.

## When to Use

- A user is tempted to send an emotional message to an ex, estranged friend, or family member
- Someone has drafted a message and wants a sanity check before hitting send
- The user is experiencing breakup grief, anger, or loneliness and wants to reach out impulsively
- Someone needs help rephrasing a hostile message into something constructive
- The user wants to practice difficult conversations in a safe space

## How It Works

1. Provide a non-judgmental space for the user to share their raw message
2. Validate their feelings without endorsing destructive actions
3. Help them identify the underlying need behind the message
4. Offer alternative ways to express themselves or process the emotion
5. If appropriate, help rewrite the message into something they won't regret

## Steps

1. **Receive the Draft**: Invite the user to share the message they want to send
2. **Validate Emotions**: Acknowledge their feelings — anger, hurt, longing are all valid
3. **Explore Consequences**: Gently help them consider how the recipient might receive it
4. **Identify the Real Need**: Is it closure? Reconnection? Being heard? Revenge?
5. **Redirect or Rewrite**: Suggest healthier outlets, or help craft a more intentional message

## Common Pitfalls

- Don't shame the user for their feelings or the message they drafted
- Avoid taking sides in relationship conflicts
- Don't offer therapy-level advice — this is a buffer, not a substitute for professional help
- Never encourage sending a message the user will clearly regret
- Don't assume you know the full relationship context

## Inputs

- `draft` -- the message the user is tempted to send (to an ex, estranged friend, or family member); or the situation: breakup grief, anger, loneliness, an impulsive urge to reach out
- `goal` -- sanity-check a draft, rephrase something hostile, or practice a difficult conversation safely

## Outputs

- Validated feelings (anger, hurt, longing are all valid -- without endorsing destructive actions), an exploration of consequences (how the recipient might receive it), the identified real need (closure? reconnection? being heard?), and either healthier outlets or a rewritten, intentional message

## Example

A 2am draft to an ex: feelings validated -> "what do you actually need from this -- closure or a response?" -> consequence walk-through -> rewritten as a calm, boundaried message saved for morning review, plus the option to not send at all.

## Errors & edge cases

- **Shaming the user** -- never shame feelings or the drafted message.
- **Taking sides** -- avoid taking sides in relationship conflicts.
- **Therapy-level advice** -- this is a buffer, not a substitute for professional help.
- **Encouraging a regrettable send** -- never encourage sending a message the user will clearly regret.
- **Assuming full context** -- don't assume you know the whole relationship story.
