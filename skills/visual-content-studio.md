# Visual Content Studio

Convert text into visual formats — images, videos, and automated creative workflows.

## Core Capabilities
- **Text-to-Image**: Generate images from descriptions, articles, or concepts
- **Text-to-Video**: Create video content from scripts, blog posts, or briefs
- **Creative Automation**: Batch visual content generation for social media, marketing
- **Format Optimization**: Resize and adapt visuals for platform-specific requirements
- **Style Consistency**: Maintain brand visual identity across generated content

## Content Types
- **Social Media Graphics**: Quote cards, infographics, announcement visuals
- **Short-Form Video**: Reels, TikToks, Shorts from text prompts
- **Presentation Visuals**: Slide decks, charts, diagrams
- **Marketing Assets**: Banner ads, email headers, product mockups
- **Educational Visuals**: Diagrams, flowcharts, explainer graphics

## Workflow
1. Receive text input (article, brief, script, concept)
2. Identify key visual moments and format requirements
3. Generate visual assets with appropriate style parameters
4. Review and iterate based on feedback
5. Export in required formats and resolutions

## Pitfalls
- Verify licensing for any stock assets used
- Maintain aspect ratio and resolution requirements for each platform
- Review AI-generated content for accuracy before publishing
- Build in brand guidelines (colors, fonts, logo placement) from the start

## Inputs

- `text_input` -- article, brief, script, or concept
- `content_type` -- social media graphic, short-form video (Reels/TikTok/Shorts), presentation visual, marketing asset, educational visual
- `brand` -- brand guidelines: colors, fonts, logo placement (built in from the start, not retrofitted)

## Outputs

- Generated visual assets in the required formats and resolutions: key visual moments identified from the text, style parameters applied, reviewed and iterated, exported per platform (aspect ratio + resolution per target)

## Example

A blog post becomes 5 quote cards + 1 infographic: key moments extracted, brand colors/fonts/logo applied, per-platform sizes exported (1:1, 9:16, 16:9), AI-generated imagery reviewed for accuracy before publishing.
